## 配置字段

为每个站点建立任务级配置，不要把未经验证的选择器写回通用脚本：

```json
{
  "approvedOrigin": "https://example.com",
  "allowedPathPrefix": "/question-bank/",
  "questionContainer": ".question-list",
  "questionItem": ".question-item",
  "stem": ".stem",
  "options": ".option",
  "answer": ".answer",
  "knowledge": ".knowledge",
  "analysis": ".analysis",
  "questionType": ".question-type",
  "theme": null,
  "optionLetterRange": "A-H",
  "judgeAnswerTexts": {"true": ["正确", "对", "√", "T"], "false": ["错误", "错", "×", "F"]},
  "onNoAnswers": "stop",
  "submitButton": "button.test_btn",
  "submitLabels": ["提交", "查看答案"],
  "paginationContainer": ".pagination",
  "nextLink": "a.next",
  "pageParam": "page"
}
```

`approvedOrigin` 和 `allowedPathPrefix` 必须来自用户批准的起始 URL，其余选择器必须通过只读 DOM 检查获得。

若站点通过同源 JSON 接口返回结构化题目（详情页由 JS 渲染时常见），先只读检查字段结构，再按字段白名单采集（题干/选项/答案/解析/知识点/题型），不得抓取整页文本。示例字段映射（仅供适配参考）：

- 题干：`data.question_stem`
- 选项：`data.question_result[]` 的 `choice`（按 `numrow` 顺序编号 A、B、C…）
- 答案：`data.answer`（选择题为字母串如 `A,B,D`；判断题为 `正确/错误`）
- 选项对错标记：`data.question_result[].right_wrong_mark`（1=正确）
- 解析：`data.analysis`（可能为空）
- 知识点/题型：`data.knowledge_point` / `data.question_type`

## 题型与字段变体（v2）

1. **判断题**：常见形态为“无选项 + 标准答案为 `正确/错误`”。页文件中可只写 `标准答案：正确`，脚本自动归一化为 `A.正确 / B.错误`，答案为 `A/B`；若页面本身给出 `A. 正确 / B. 错误` 选项，则按选项文本映射到对应字母。题库与质量报告必须注明“A=正确，B=错误”的映射关系。
2. **多选项题**：选项字母可能超过 A–D（常见 A–E、A–F），答案可能出现 `BDE`、`ABCEF`、`E`。脚本支持 **A–H**，并按完整答案字符串校验：任何答案字母不在选项中即隔离，**禁止截断**（如 `ABCEF` 不能被截成 `ABC`）。
3. **题型字段**：页文件可选 `题型：判断题/单选题/多选题/…`，题库会输出题型并在质量报告中统计；未提供时脚本按“判断题/多选/单选”推断。
4. **主题字段**：页文件可选 `主题：<主题名>`；单一知识点题库可用 `--group-by theme` 按主题分组（题库/知识体系/质量报告均输出主题分布）。
5. **解析缺失**：解析字段允许为空（质量报告计数）；知识体系可按“题干+标准答案”推导规则要点，但必须注明“平台未提供解析、未补写”，不得把错误选项或题目外知识写成事实。

## 无标准答案停止策略

若采集/解析结果显示题库**没有任何标准答案**：

1. **立即停止任务**，不得自行作答、推断、搜索答案或伪造解析；
2. 向用户报告“题库未提供标准答案”，并请用户确认下一步动作：提供答案来源 / 仅整理题干（不含答案）/ 终止任务；
3. 命令行默认 `--on-no-answers stop`：脚本打印停止原因并以**退出码 2** 结束，不写交付文件；只有用户明确同意继续时，才可用 `--on-no-answers isolate` 仅隔离无答案题并保留质量报告；
4. 严禁把任何“推测答案”“模型作答”当作标准答案写入题库或知识体系。

## 首次适配

1. 只读列出候选题目容器、题目数、按钮文字和下一页目标。
2. 确认选择器只覆盖题库，不包含账户、订单、通知或导航区域。
3. 展示一个脱敏后的题目样例和将要点击的控件数量。
4. 获得用户确认后才允许提交答案和翻页。
5. 保存本次任务配置；不要假设它适用于网站的其他版本。

## 每页检查

- 来源和路径仍在允许范围。
- 题目容器唯一且可见。
- 题目数处于配置允许范围，不使用全站固定常量。
- 待点击控件都位于题目项内且文字、类型符合配置。
- 抓取结果只包含结构化题目字段。
- **答案字段存在性检查**：若整页/整库无标准答案字段或值全空，按“无标准答案停止策略”处理。
- **完整答案校验**：答案字母必须全部存在于选项中，禁止截断；无法确认时隔离并报告。
- 判断题归一化需在题库/质量报告中注明 A/B 映射。
- 下一页 URL 经解析后同源、路径合法且页码递增。

## 终止条件

以下任一情况立即停止并交付部分结果：来源或路径变化、容器缺失或多义、页码不递增、URL/页码/内容哈希重复、连续失败达到 3 次、达到任一用户批准预算、页面要求执行额外登录或敏感操作、**题库未提供标准答案（须停止并通知用户确认）**、**答案解析出现无法确认的截断/超出选项范围（隔离并报告，不得静默通过）**。

## xpcle.com 历史提示

旧页面曾使用 `.test_btn` 和含“下页”的链接，每页曾常见 12 题。这些仅是历史线索，不是可信配置。每次运行都必须重新验证容器、控件语义、下一页目标和实际题数。
